# 第二轮交付：几何修复、分层海水与沉浸式 UI

## 修改摘要与问题根因

| 项目     | 根因                                                                             | 修复                                                                                                                                                  |
| -------- | -------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| P1 店门  | 固定门框、橱窗、门扇分别硬编码，门扇顶部侵入招牌下沿，门前立柱又进入开门扇形区域 | Storefront 统一门洞、窗格、门扇尺寸；固定玻璃只填充相邻立柱之间；门扇绕左侧独立铰链旋转，门底高于地板、门顶低于招牌。入口留出立柱缺口，完整扫掠有测试 |
| P2 栏杆  | 左杆几何指向 +X、右杆指向 -X，但旋转符号与局部方向相反，两个端点都向 -Y 转动     | 每侧独立 pivot，角度为 -side × angle。竖起的端点始终朝 +Y；初始化即正确竖直，全角度检查最低点高于道路                                                 |
| 电车周期 | 原逻辑在落杆后把车从展示位置重置至 -10，周期结束又从 11 跳回 2.5                 | 在 ±4.7 两个停车位置之间连续行驶，完全清空道路后再抬杆；下一周期反向行驶，无重置瞬移                                                                  |
| P2 太阳  | 可见圆盘位于沙盘后方很近的位置，与真实远景比例不符                               | 删除圆盘及硬编码太阳水面条纹，不用其他圆盘替代；保留背景、环境光、车灯、路灯及水色渐变                                                                |
| 海水     | 只有单层 Plane，整块不透明底座遮住水下，原 CPU 顶点起伏也没更新法线              | 陆地底座在海岸处截止；添加有厚度的水面/侧壁、缓坡海床和水下岩石，GPU 解析波与法线、水色统一更新                                                       |
| P6 UI    | Canvas 固定只占 75% 视口，大标题占左侧；相机用固定视锥                           | 全视口 Canvas，删除大标题区，改为小品牌与悬浮工具；正交相机根据模型包围盒和屏幕比例拟合                                                               |
| 海岸涟漪 | 高度固定 .045，埋在斜坡道路下                                                    | 涟漪高度按所在坡路 Z 坐标计算                                                                                                                         |

P3–P5 仅作为水体厚度、透明度、微缩质感的参考，没有复制船只、港口、生态系统或整张图片。樱花保持静态，没有飘落花瓣、自动环绕或电影模式。

## 水体与 UI 方案

详细的官方 Water、五个 GitHub 项目和 A/B 材质比较见 [RESEARCH.md](RESEARCH.md)。正式采用 **轻量 GLSL + 分层几何**，没有引入新依赖或实时反射渲染目标。

水面和侧壁共用解析波场及时间/昼夜参数；同一边界采样确保水位连续。水深约 .9 个场景单位，透明表面不写深度；水下包含渐变海床、程序化焦散与 22 个实例化岩石。反光是天空光色与 Fresnel 近似，不是物理折射或真实建筑倒影。

保留现有深蓝色、暖灯和 Low-poly 场景风格。品牌左上、帮助右上、场景按钮左下（窄屏底部居中）、天气/昼夜/重置底部居中。无输入约 5 秒降低非必要 UI 透明度，任何输入恢复；不移动相机、不改变场景。HTML 交互区域与 Canvas 分离，文字/装饰不截获指针事件。

## 构建、测试与性能证据

- `npm run build`：成功，包含 TypeScript 类型检查、主页面和实验页生产打包。
- `npm test`：8 项通过，包括门 151 个角度样本、两侧栏杆各 181 个角度样本、连续电车周期、水面/侧壁边界、岩石边界。
- 浏览器共 5 项用例验证通过；4 项综合通过，物理材质原型的 Shader 拼接换行问题修正后，剩余 1 项定向重跑通过。
- 浏览器控制台无新的异常或 Shader 编译错误。此前原型拼接错误已修复；不会绕过着色器异常检查。
- 桌面完整道口：警示 → 落杆 → 电车穿越 → 清空道路 → 抬杆 → 待机；重复点击被拒绝；水平和竖直状态均有截图。
- 单指旋转、轻触点击、双指缩放与拖动防误触通过 Chromium 触屏模拟。
- 帮助、天气和重置等 UI 按钮没有触发三维物件；空闲淡化不改变相机位置。
- 连续五轮场景切换，GPU geometry **217 → 217**、texture **3 → 3**，无持续增长；最后海岸帧 220 次绘制。
- 水体隔离模块：5 次绘制，5 个 geometry；正式 Shader 路径 0 张纹理，物理原型 1 张 64×64 纹理。未新增反射场景渲染或每帧 CPU 波面上传。
- 保留桌面 DPR 1.75 / 粗指针 1.35 上限、慢帧降至 1、桌面/触屏 2048/1024 主光阴影以及低成本雨线/实例化涟漪。
- 生产预览服务器 4173 实际打开双场景及两种实验材质，三维三角形实际渲染，控制台错误列表为空。
- Vite 仍有 Three.js 分包约 501 kB 的体积提示（gzip 约 126.7 kB），不影响构建。
